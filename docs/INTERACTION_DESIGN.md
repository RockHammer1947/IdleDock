# 本地算力队列：界面与操作约定

界面服务于一边工作、一边等待本地批量任务的用户。优先展示当前任务、可执行的控制和等待原因；没有实测进度时不伪造百分比。保留系统字体、SF Symbols、原生设置表单和紧凑布局，不使用持续装饰动画。

## 信息层级

- 「队列」页：当前任务、暂停/停止、任务筛选、产物预览。
- 「系统」页：CPU/GPU/内存指标、功耗、耗电估算、保护阈值入口。
- 固定底栏：设置、运行方式、置顶、紧凑视图。
- 当前任务从普通列表中分离，按 provider 展示摘要与产物类型。
- 警告与保护原因保持可见；正常高利用率本身不等同于过热。

## 运行方式与授权

手动、智能空闲、每日时段互斥。选择选项只是预选；明确点击启动、启用或应用才改变队列模式。保存时段或空闲阈值不启用计算。取消预选应回到当前实际模式。

运行中提供「本段后暂停」和「立即停止」。前者等待当前任务结束；后者请求清理当前任务并将未完成内容重新排队，界面显示停止反馈。不要把“停止请求已提交”显示为“已释放所有计算资源”：包装器可能仍在清理或恢复常驻服务。

切换页签、筛选、打开设置、置顶或收起列表不产生队列启动命令。关闭应用不停止后台 worker。后台运行方式与活跃任务不能因界面重启而重置。

## 多 provider 展示

音频任务显示配音摘要、音频图标与试听入口；视频任务显示尺寸/时长与预览；其他文件提供打开产物。未知音频时长不填成零秒视频。

当前任务的阶段为等待计算资源、准备、执行、恢复。等锁时间不算模型生成进度。JSON 导入识别单项和批次；导入不启用运行，但已启用的队列可能开始新导入的任务。

任务区提供等待、已完成、失败、已取消和全部筛选。任务操作通过显式菜单提供，删除仅针对已结束任务并遵循明确删除意图。技术验收通过不表示用户已批准音质、画面或口型。

## 机器指标

CPU/GPU/内存圆环同时展示数字和文字，不只用颜色传达状态。CPU 使用连续采样差值，GPU 读取监测数据，内存使用 macOS 内存压力信息。缺失、失联或过期读数保持未知，不显示成零。

平均传感器温度不代表芯片热点或厂商热限值。芯片功率和由其估算的整机电量不是插座实测值，也不是某个模型独占耗电。保护阈值块进入设置，不提供绕过保护的一键捷径。

## 开发预览与验证

给构建后的 `config.json` 增加 `preview` 字段，指向隔离 status JSON，可预览暂停、执行、智能等待、保护停止、空队列、停止中和各产物类型。预览模型拒绝队列写操作；正式使用移除该字段。

验证完整/紧凑视图、告警可见性、运行方式的预选与应用差异，以及不同 provider 的预览菜单。仅重启对应的应用可执行程序，不重启 worker、supervisor 或模型包装器。构建和系统指标检查见 [CONTRIBUTING.md](../CONTRIBUTING.md)，本次实际验证范围见 [VALIDATION.md](VALIDATION.md)。
